# rag/

Notes on retrieval-augmented generation: indexing, chunking, retrieval strategies, and grounding.

## What belongs here

- Chunking strategies (size, overlap, semantic vs structural)
- Embedding choices and tradeoffs
- Retrieval patterns (top-k, MMR, hybrid sparse+dense)
- Grounding and citation discipline
- When RAG helps vs when it adds noise
- Index freshness and update cadence

## What doesn't belong here

- Notes on the self-improving learning loop → `evals/` or `orchestration/`
- Notes on the MCP tools that serve retrieval → `mcp/`
