# skills/

Notes on Claude Code skill patterns: how to design, invoke, and chain skills effectively.

## What belongs here

- Skill design principles (trigger clarity, scope, side effects)
- When a skill is the right abstraction vs a hook, a command, or an MCP tool
- Skill chaining and composition
- How skills interact with the worktree protocol
- Skills that operate on the repo itself (self-maintenance)
- The `/field-note` skill itself (this mechanism, dog-fooded here)

## What doesn't belong here

- Notes on MCP tools that skills call → `mcp/`
- Notes on hooks specifically → `infra/`
