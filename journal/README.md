# journal/

Timestamped entries: wave summaries, surprises, and what I'd do differently.

## What belongs here

- Wave completion summaries (what shipped, what surprised me, what I'd change)
- Pivots and why they happened
- Docs/org decisions that changed between waves
- Honest accounts of things that broke before they worked

## File naming

```
YYYY-MM-DD-wave-N-description.md
```

Example: `2026-05-30-wave-1-harness-and-worktrees.md`
