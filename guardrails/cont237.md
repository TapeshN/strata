`tools/brief_base_check.py` + `scripts/checks/brief_base_exists.sh` — every brief's base branch must resolve on the remote it names. Trigger-verified against the REAL pre-fix briefs recovered from git history rather than a synthetic fixture, which also proves the historical defect was catchable.

when a ruling constrains an artifact CLASS, fixing the instances that prompted it is half the job; sweep the class in the same turn, or the ruling is decoration. And per rule 16, a recurrence despite a documented rule earns a gate rather than more prose — the second occurrence is the trigger, not the third.
